Создай полноценный высококачественный Paper плагин LoveActivities для Minecraft  26.2 (JDK 25).

Плагин должен быть максимально стабильным, быстрым, полностью асинхронным, без лагов, без пустых try-catch и с правильной обработкой всех крайних случаев. Особое внимание удели стабильности системы ставок и мгновенному возврату валюты.

### 1. Технические требования
- Версия: Minecraft 26.2, Java 25
- Ядро: Paper / Purpur
- Обязательные зависимости: PlaceholderAPI, LoveCore (для физической валюты и уведомлений), SQLite
- Всё взаимодействие строго через GUI (кроме начального вызова)
- Все кнопки в GUI — только base64 головы
- Все головы хранятся в отдельном файле `heads.yml`
- Полная локализация в `messages.yml` (русский + английский)
- Конфиг + messages + heads поддерживают горячую перезагрузку
- Индивидуальные настройки каждого игрока хранятся в SQLite
- Статистика игроков хранится в SQLite

### 2. Команды

Игровые команды (каждая игра имеет английскую и русскую версию):
- /chess <ник> и /шахматы <ник>
- /blackjack <ник> и /блэкджек <ник>
- /dice <ник> и /кости <ник>
- /rps <ник> и /кнб <ник>
- /gwent <ник> и /гвинт <ник>
- /cards <ник> и /карты <ник> (обычные карты: Дурак, Война и т.д.)

Служебные команды игрока:
- /loveactivities settings — личные настройки + чёрный список игр
- /loveactivities disable — включить/выключить режим «Не беспокоить» (не принимать запросы)

Админ-команды (без пробела):
- /loveactivitiesadmin reload
- /loveactivitiesadmin endgame <игрок>
- /loveactivitiesadmin stats

### 3. Система вызова на игру (обязательна для всех игр)

1. Игрок 1 пишет команду (например /шахматы Игрок2)
2. Проверки перед отправкой:
   - Игрок2 онлайн
   - Оба игрока в радиусе ≤ 3 блоков
   - Никто не находится в активной игре или запросе
   - У Игрока2 не включён режим «Не беспокоить»
   - Игра не находится в чёрном списке у любого из игроков
   - Кулдаун на запросы
3. Игроку 2 в чат приходит сообщение с двумя кликабельными кнопками: [Принять] и [Отменить]
4. Игроку 1 приходит сообщение «Запрос отправлен» + кнопка [Отменить]
5. Игрок 1 может отменить запросом кнопкой или написав в чат «отменить» / «cancel»
6. При принятии открывается GUI:
   - «Играть со ставкой»
   - «Играть без ставки»
7. Если выбрана ставка:
   - Открывается общее GUI ставок:
     - Левая сторона — Игрок 1 (пригласивший)
     - Правая сторона — Игрок 2
     - Кнопки подтверждения по бокам
   - Каждый игрок ставит свою сумму через физическую валюту LoveCore
   - Оба должны нажать «Подтвердить»
   - После подтверждения обоих запускается отсчёт 3 секунды ТОЛЬКО внутри GUI
   - Любая отмена / закрытие GUI / выход = мгновенный возврат ставок обоим
8. Если выбрано «без ставки» — игра начинается сразу

### 4. Правила автолуза и возврата ставок
Автоматический проигрыш + мгновенный возврат ставки победителю (или обоим, если игра не началась) происходит при:
- Закрытии GUI (Escape)
- Нажатии кнопки «Сдаться» / «Выход»
- Отходе дальше 3 блоков
- Смерти
- Выходе с сервера / кике
- Смене мира
- АФК (нет хода X секунд — настраивается)
- Любом другом принудительном закрытии сессии

Ставка возвращается мгновенно через API LoveCore.

### 5. Список игр
1. Шахматы
2. Блэкджек
3. Кости (несколько режимов)
4. Камень-Ножницы-Бумага
5. Гвинт (адаптированный, карты через base64 heads, ряды, погоды, раунды, обучающее меню)
6. Карты (Дурак подкидной + Простая война)

Для сложных игр (Гвинт, Блэкджек, Кости, Карты) обязательно полноценное обучающее GUI.

### 6. Система настроек игрока (/loveactivities settings)
GUI с кнопками-переключателями (base64 головы):
- Включить/выключить каждую игру отдельно (чёрный список)
- Включить/выключить все игры одной кнопкой
- Звуки вкл/выкл
- Частицы вкл/выкл
- Режим «Не беспокоить» (дублирует /loveactivities disable)

Все настройки сохраняются индивидуально в SQLite.

### 7. Статистика и PlaceholderAPI (обязательно)
Для каждого игрока и каждой игры хранится:
- Количество побед
- Количество поражений
- Сумма выигранных ставок
- Сумма проигранных ставок

Плейсхолдеры (примеры):
%loveactivities_wins_chess%
%loveactivities_losses_chess%
%loveactivities_won_money_chess%
%loveactivities_lost_money_chess%
%loveactivities_wins_total%
%loveactivities_top_wins_chess_1% и т.д. (топ)

### 8. Анти-абуз
- Нельзя отправлять запрос самому себе
- Нельзя иметь больше одного активного запроса
- Кулдаун на запросы
- Защита от дюпа ставок при одновременном закрытии GUI
- Проверка, что ставка реально снята перед стартом игры
- Защита от кликов по устаревшим GUI
- Максимальная ставка (глобально и на игру)
- Логирование всех ставок и результатов в bets.log

### 9. Файлы
- config.yml
- messages.yml
- heads.yml (все base64 головы)
- database (SQLite)
- bets.log

### 10. Архитектура и качество кода
- Модульная структура (менеджеры: SessionManager, BetManager, RequestManager, StatsManager, SettingsManager)
- Полная асинхронность (CompletableFuture + async scheduler)
- Никаких пустых try-catch
- Безопасный откат ставок при любом исключении
- Правильная очистка сессий после окончания игры
- Использование API LoveCore для валюты и уведомлений

Сделай код чистым, читаемым, с правильной обработкой всех edge-cases.
Сначала реализуй ядро (вызов → ставки → сессии → автолуз → настройки → статистика), затем игры по одной.
